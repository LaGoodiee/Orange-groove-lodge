# Orange Grove Lodge website
Static site (no build step). Deploy on Vercel: Framework Preset "Other", leave Build Command and Output Directory empty.

- Edit contact details, rooms and copy in `index.html`.
- WhatsApp booking number: search `const WA=` in `index.html` (country code, no +).
- Domain: orangegrovelodge.com.ng (www redirects to it via `vercel.json`).
